# 🎨 Abstract Soul Art - Mirror of the Soul

An artistic exploration of loneliness, darkness, and the struggle for freedom through ASCII art, poetry, and interactive web experiences.

## 📁 Contents

- **README.md** - Documentation and setup guide
- **mirror.html** - Interactive mirror webpage with CSS/JavaScript effects
- **ASCII Art & Poetry** - Text-based artistic expression

## 🌟 Features

### Interactive Mirror
An immersive experience featuring:
- 🪞 Golden ornate mirror frame with realistic shine effects
- 🔄 Dual reflection system showing original and mirrored text
- 🎭 Multiple thematic scenes (Freedom, Journey, Hope, Transform)
- ✨ Particle effects and smooth animations
- 🖱️ 3D parallax effect that responds to mouse movement
- 🎬 Auto-transitioning scenes every 6 seconds

### Interactive Buttons
Transform the mirror's message with themed buttons:
- **🕊️ Freedom** - Rise and be free
- **🌅 Journey** - Ascending voyage
- **✨ Hope** - Glowing possibilities
- **🔄 Transform** - Becoming whole
- **💫 Particles** - Magical effects

## 🚀 How to View

### Option 1: GitHub Pages (Recommended)
1. Go to **Settings** → **Pages**
2. Under "Build and deployment":
   - Select **Source**: Deploy from a branch
   - Select **Branch**: `main`
   - Select **Folder**: `/ (root)`
3. Click **Save**
4. Your site will be available at: `https://eliaswilson421-blip.github.io/abstract-soul-art/mirror.html`

### Option 2: Local File
Simply download `mirror.html` and open it directly in your web browser.

### Option 3: Raw GitHub
Click the download button on the mirror.html file and open it locally.
